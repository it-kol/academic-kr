제품 브리핑

영상 제작 전 꼭 읽어주세요. 아래 내용이 전환율에 직접적인 영향을 미칩니다.

기능 중요도 핵심 설명 추가 설명
BabelDOC · PDF 번역 ★ 필수 arXiv / PubMed 논문 PDF를 수식·표·다단 레이아웃 그대로 이중 언어로 번역. 다른 도구와 가장 차별화되는 핵심 기능. BabelDOC 엔진 선택 시 수식 깨짐 없음. 무료 사용 가능.
웹페이지 이중 언어 번역 ★ 필수 arXiv / PubMed / IEEE Xplore 원문 + 번역문 동시 표시. 브라우저 기본 번역보다 학술 독해에 훨씬 적합.
영상 자막 번역 ★ 필수 YouTube 학술 강의·컨퍼런스 영상 실시간 이중 언어 자막. 자막 내보내기 지원. YouTube 라이브 번역 지원(자막 있는 방송 한정). 자막 내보내기 → Notion에 붙여넣으면 학습 노트로 즉시 활용.
AI Reply · 이메일 답장 ◎ 심화 Gmail에서 지도교수 이메일 한 번에 요약하고 영문 답장 초안 생성. 어조 미세 조정 후 바로 발송.
입력창 번역 선택 어떤 입력창에서든 한국어로 쓰고 영어로 즉시 변환. 이메일·논문 초안 작성 시 유용. —
이중 언어 전자책 선택 영문 전자책을 이중 언어 버전으로 변환. 학술서·교재 독해에 활용. —

Production Tips

핵심 제작 포인트

높은 전환율 영상을 만들기 위한 실질적인 조언입니다. 강제 사항이 아닙니다.

🎯 콘텐츠 포지셔닝 & 오프닝 설계
1
오프닝에 반드시 갈등 요소: 실제 학술 고민으로 시작, "안녕하세요 저는 ○○입니다"로 시작하지 마세요. 예: 「arXiv 논문 Google 번역으로 돌렸더니 수식이 다 깨졌죠? 이 툴로 완전히 해결했어요」
2
실제 학술 장면 보여주기: 기능 인터페이스만 보여주지 말고, 실제로 사용하는 장면을 보여주세요 (arXiv 논문 번역, 지도교수 이메일 답장, YouTube 학술 강의 시청 등).
3
비교 장면이 가장 임팩트 강함: 「Google 번역 vs Immersive Translate」 비교 장면 추가, 특히 PDF 레이아웃 보존 효과 — 전환율 가장 높은 콘텐츠 형식.
4
CTA는 구체적으로: 마무리에 「댓글에 공식 링크 + 구독자 전용 할인 코드 남겨뒀어요」 명확히 말하기, "검색해보세요"로 끝내지 마세요.

Installation Guide

설치 가이드

영상에서 설치 과정을 완전히 보여주는 것을 추천합니다. 시청자가 가장 많이 막히는 부분입니다.

1
공식 홈페이지 열기
immersivetranslate.com/ko/ 접속, 「무료 설치」 버튼 클릭, Chrome 웹스토어로 이동
2
확장 프로그램 추가
「Chrome에 추가」 클릭, 팝업에서 「확장 프로그램 추가」 클릭, 설치 완료 후 툴바에 아이콘 표시
3
논문 페이지 열기
arXiv / PubMed 논문 페이지 접속, 확장 아이콘 클릭, 「이 페이지 번역」 선택
4
BabelDOC 체험
「PDF 번역」 클릭 → BabelDOC 엔진 선택, 논문 PDF 업로드, 이중 언어 버전 생성 완료
1
앱 다운로드
App Store에서 「Immersive Translate」 검색, 또는 공식 홈페이지에서 Android APK 다운로드
2
계정 로그인
이메일로 로그인, 무료 버전 바로 사용 가능, Pro 사용자는 데스크톱 설정 동기화 가능
3
PDF 번역
「문서 번역」 클릭, 논문 PDF 업로드, 목표 언어 선택, 이중 언어 버전 생성 대기
4
몰입 독서 시작
내장 브라우저에서 학술 사이트 열고, 번역 버튼 클릭하면 이중 언어 대조 독서 가능

Collaboration Process

협업 프로세스

복잡하지 않아요. 총 7단계, 보통 2–3주면 영상 업로드까지 완료됩니다.

01
첫 번째 단계
협업 의향 확인
이메일 또는 Discord로 연락주시면 24시간 내에 답변드립니다. 채널 정보(플랫폼, 구독자 수, 콘텐츠 방향)를 간단히 알려주시면 됩니다.
📧 이메일 💬 Discord
02
두 번째 단계
콘텐츠 방향, 보수, 제휴 플랜 조율
콘텐츠 방향, 업로드 일정, 보수를 확인합니다. 이 페이지를 이미 읽으셨다면 콘텐츠 방향은 대부분 정리된 셈이라 이 단계는 가볍게 진행됩니다.
또한 이 단계에서 Immersive Translate 제휴 프로그램 참여 여부도 확인합니다 — 이에 따라 할인 코드 설정 방식이 달라집니다. 제휴 파트너는 전용 추천 링크를 통해 지속적인 커미션을 받을 수 있어 장기 파트너십을 원하는 크리에이터에게 적합합니다.

Privacy

개인정보 보호

번역 내용에는 민감한 정보가 포함될 수 있습니다. Immersive Translate는 개인정보 보호를 제품 설계의 핵심으로 삼고 있습니다.

🔒
프라이버시 모드 (OneAIFW)
로컬 비식별화 · 클라우드에 원문 없음
「로컬 인식 → 로컬 비식별화 → 클라우드 번역 → 로컬 복원」 순환 프로세스 적용. 이름, 주소, 계좌번호, 비밀번호, 개인키 등 민감 정보는 사용자 기기 밖으로 나가지 않습니다.
  • 민감 정보는 익명 플레이스홀더로 대체, 클라우드는 비식별화된 텍스트만 처리
  • 비식별화 데이터는 브라우저 메모리(RAM)에만 임시 저장, 브라우저 종료 시 자동 삭제
  • MIT 라이선스로 오픈소스 공개, 커뮤니티 감사 가능
🛡️
데이터 무보존
